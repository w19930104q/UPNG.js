# UPNG.js interoperability regression

Verifies that UPNG.js (at the pinned commit) interoperates with standard PNG
tooling, without modifying the library. Three directions, checked per sample:

| direction | check |
|---|---|
| **decode** | `UPNG.decode` + `UPNG.toRGBA8` of a reference PNG equals the known reference pixels |
| **roundtrip** | `UPNG.decode → UPNG.encode → UPNG.decode` is pixel-stable |
| **encode** | `UPNG.encode` / `UPNG.encodeLL` output decoded by a standard decoder (Pillow) equals the source pixels |

## Run

```sh
npm install          # pako (the library's only dependency)
test/run_all.sh      # exits non-zero if any sample fails
```

Requires Node.js and Python 3 with Pillow + numpy. Results are printed as a
sample matrix and written to `test/out/RESULTS.md`.

## Sample matrix

Generated by `test/gen_refs.py` into `test/refs/` (regenerated on every run;
deterministic). Coverage:

- **bit depths**: 1/2/4/8/16 — grayscale `gray1..gray16`, truecolor
  `rgb8/rgb16`, gray+alpha `ga8/ga16`, RGBA `rgba8/rgba16`, palette
  `pal1/pal2/pal4/pal8`
- **palette**: 2/4/16/256-entry palettes, partial-alpha `tRNS`
  (`pal4_trns` with a short tRNS, `pal8_trns`)
- **transparency**: `tRNS` for gray (`gray4/8/16_trns`) and RGB
  (`rgb8/16_trns`), alpha channels (`ga*`, `rgba*`), fully transparent pixels
  with non-zero RGB
- **edge shapes**: 1×1 (`rgba8_1x1`), byte-aligned and padded sub-byte rows
  (`gray1_w8`, `gray1_w7`), odd 37×23 geometry throughout
- **filtering**: `rgb8_filters` cycles all five PNG filter types
- **encoder diversity**: references are written both by a minimal in-tree
  spec writer and by Pillow (`pil_*`), so neither direction depends on one
  encoder's choices
- **encodeLL**: explicit ctype/depth encodes `ll_*` (gray/GA/RGB/RGBA ×
  8/16-bit); 16-bit gray is compared at full 16-bit precision
- **quantize**: `quantize64` smoke-checks the lossy `ps>0` path (size +
  ≤64 colors; pixel equality is not required by design)

Every reference file is cross-validated with Pillow at generation time, so a
broken generator fails before the library is ever invoked.

## Layout

- `gen_refs.py` — builds the reference matrix + expected RGBA8 dumps
  (`refs/<name>.png`, `refs/<name>.rgba`, `refs/matrix.json`)
- `interop.js` — Node side: decode/roundtrip checks, writes UPNG-encoded
  PNGs to `out/`; loads `UPNG.js` unmodified via `new Function` (the library
  is a browser-style script with no `module.exports`)
- `check_encode.py` — Pillow side: verifies UPNG encoder output, merges
  results into the acceptance matrix (`out/RESULTS.md`)
- `run_all.sh` — orchestrates all three stages

## Known scope limits

- Adam7 interlaced references are not generated (Pillow cannot write them);
  interlace decode is untested here.
- APNG animation, `sRGB`/`iCCP`/`pHYs` ancillary chunks, and the dithering
  path are out of scope.
- Pillow quirks are accommodated, not treated as library failures: it does
  not apply `tRNS` for sub-8-bit grayscale, and it expands 16-bit
  gray+alpha to RGBA.
